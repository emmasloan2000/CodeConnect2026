# Kainos Code Connect Challenge 2026

An employee management web application built by a team of four during the Kainos Code Connect Challenge at Queen's University Belfast (18–19 May 2026).

## The challenge

Kainos set the MSc cohort a two-day experiential learning event. Teams were allocated on the day and worked in an agile way, with Kainos mentors, to build an application for a mock client, the Kainos People Support team, who need to keep accurate, up-to-date information about their employees.

The event was not a competition, and the aim was industry experience, not a finished product: working in a cross-functional team, applying classroom learning to a real-style problem, and presenting to stakeholders.

## How we worked

- Two one-day sprints, each with sprint planning, a daily stand-up, a show and tell, and a retrospective
- A shared sprint board and a GitHub repository with feature branches
- A show and tell to the mock clients on day two, where we demonstrated the front and back end and how we acted on the feedback from day one

## Features

<!-- Check this list against what the app actually does, and edit it -->

- View a list of employees
- Add, edit and delete employees
- Employee address details
- User roles, with an admin dashboard
- Responsive, formatted employee list and forms

## Tech

Node.js and Express, with JSON file storage, as recommended in the brief.

## Run it

```bash
git clone https://github.com/emmasloan2000/CodeConnect2026.git
cd CodeConnect2026
npm install
npm start
```

Then open http://localhost:3000.

## Notes

This was built in two days as a learning exercise, so it is a prototype rather than production software. With more time we would have added more detailed employee records, search and filtering, and automated tests.
